# 벽·문·창 디테일 라이브러리

계획설계 생성기(`tools/gen_plan.py`)가 평면을 만들 때 읽는 기준입니다. 값을 바꾸고 다시 생성하면 모든 층·세대에 한 번에 반영됩니다.

| 파일 | 내용 | 예: 바꾸면 |
|---|---|---|
| `walls.json` | 벽 종류별 두께(`t`, m)·표시 이름·구성(layers)·CAD 표현 | `partition.t` 0.10 → 0.12 : 세대 내 칸막이가 모두 120mm |
| `doors.json` | 문 폭(`sizes`)·높이, 문짝 방식·방화 등급·문틀·도면 태그 규칙 | `sizes.bath.w` 0.8 → 0.9 : 욕실문 285개가 900mm |
| `windows.json` | 실 이름별 창(`byRoom`: 종류·최대 폭·창대·높이), 창 종류별 개폐·창호·유리·태그, 난간 기준 | `byRoom.침실1.h` 1.4 → 1.5 : 침실1 창 높이 1.5m |

## 벽 종류 (walls.json `types`)
| 키 | 두께 | 이름 |
|---|---|---|
| exterior | 0.30 | 외벽 (RC 200 + 내단열 100) |
| basement | 0.40 | 지하 외벽 (RC 400) |
| core | 0.25 | 코어벽 (RC 250, 내력) |
| core_inner | 0.20 | 코어 내부벽 |
| party | 0.20 | 세대간 경계벽 |
| unit_corr | 0.20 | 세대-공용 경계벽 |
| fire | 0.20 | 방화구획벽 |
| partition | 0.10 | 세대 내 칸막이 (경량 100) |
| light | 0.15 | 칸막이벽 (조적·경량 150) |

## 문 (doors.json)
- 크기: 세대 현관 1.0 · 욕실 0.8 · 침실·드레스룸·다용도실 0.9 · 수납 0.8 · 공용 0.9 · 알코브 미닫이 최대 2.4 (m), 높이 2.1
- 이름에 “방화”나 “현관문”이 들어가면 갑종 방화문 + 강재 문틀 (태그 FSD), 그 밖은 목재 문틀 (태그 WD)
- 승강기 문 2짝 미닫이 (ED), 미닫이 (SLD), 폭 1.5m 이상 양개 여닫이

## 창 (windows.json)
- 거실 3.6×2.2 (창대 0.1, 바닥까지) · 침실 2.4×1.4 (창대 0.9) · 주방 1.2×1.0 · 다용도실 0.9×0.9 · 욕실 0.6×0.6
- 거실·침실창은 미서기 PVC 이중창 (폭 3m 이상 4짝), 그 밖은 위걸이 프로젝트창, 욕실은 불투명 유리
- 2층 이상에서 창대 0.9m 미만인 여닫는 창에는 높이 1.2m 추락방지 난간

## 사용법
- Claude에게: “욕실문 폭 0.9m로 바꾸고 계획설계 다시 생성해줘”, “침실창을 2.1m 폭으로 줄여줘”
- 직접 고친 뒤: 계획설계 페이지에서 다시 생성하거나 Claude에게 “계획설계 다시 생성해줘”
- 생성 결과의 문·창에는 `tag`(FSD·WD·SLD·ED·PW·CW)가 붙어 창호 일람과 CAD 도면 태그로 이어집니다.
