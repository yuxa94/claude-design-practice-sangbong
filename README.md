# 상봉동 116-49 · 대지에서 인허가 검토까지 (실습 폴더)

대지 정보와 벽·문·창 디테일만 들어 있는 빈 폴더에서 시작해, Claude에게 요청하며 **대지 경계 → 조닝 → 계획설계 → 실 디테일 → 법규·인허가**까지 진행합니다.

## 시작
1. 이 폴더를 Claude 앱 Code 탭에서 엽니다.
2. Claude에게: **“로컬호스트 띄워줘”** → http://localhost:8770/ (작업 허브)
   - 직접 켤 때: `PORT=8770 python3 tools/zoning_server.py`
3. 허브에서 단계 카드를 눌러 페이지를 엽니다.

## 처음 들어 있는 것
| 폴더 | 내용 |
|---|---|
| `site/` | 대지 조사 정리(md)·원자료(zip)·지적/건물/용도지역(raw)·대지 경계 좌표(site_geometry.json)·주변 맥락 |
| `details/` | 벽·문·창 디테일 라이브러리 (계획설계 생성기가 읽음) |
| `reference/` | 법규 검토서 (소방 중점) |
| `tools/` | 서버·대지 경계·계획설계 생성기 |
| 페이지 | 허브(index.html)·조닝 편집기·계획설계·법규인허가 |

## 단계와 요청 문장
| 단계 | Claude에게 | 내가 직접 | git 태그 |
|---|---|---|---|
| 0 시작 | “로컬호스트 띄워줘” | 허브·빈 조닝 편집기 확인 | `step-0` |
| 1 대지 경계 | “site 폴더의 대지 정보로 조닝 편집기에 대지 경계와 건축한계선을 표시하고, 1층 외곽선을 잡아줘” | 대지 면적·건폐율 확인 | `step-1` |
| 2 조닝 | “요청 반영해줘” | 층 추가, 세대·코어·복도·주차·램프 구역 그리기, 구역에 요청 남기기 | `step-2` |
| 3 계획설계 | “조닝을 바탕으로 계획설계 만들어줘. 벽·문·창은 details 폴더 기준으로” | 실·벽·문·창, 세대·이슈 탭 확인 | `step-3` |
| 4 실 디테일 | “계획설계 요청 반영해줘” · “욕실문 폭 0.9m로 바꾸고 다시 생성해줘” | 타입 탭에서 실·문 옮기기, 객체에 요청 남기기 | `step-4` |
| 5 법규·인허가 | “법규 검토 정리해줘” | 판정 목록·도면 표시 확인, 사람 판정·메모 | `step-5` |

- 페이지에서 객체(구역·벽·문·창·실)를 고르고 **✦ Claude에게 수정 요청**(단축키 C)으로 한 줄 요청을 남깁니다. 요청은 JSON에 저장만 되고, 대화창에서 “요청 반영해줘”라고 해야 반영됩니다.
- 단계가 끝나면 Claude에게 **“커밋해줘”** (메시지 `step-N: …`).

## 늦었을 때 따라잡기 (완성본 저장소에서)
```bash
git remote add answer https://github.com/yuxa94/claude-design-practice-sangbong.git   # 한 번만
git fetch answer --tags
git checkout -B my-step3 step-3              # 원하는 단계 상태로
```
지금 작업을 버리지 않으려면 먼저 `git stash` 또는 커밋하세요.

## 다른 대지로 하려면
`site/` 폴더(대지 조사 정리·원자료·`site_geometry.json`·주변 맥락)와 `project.json`(용도지역·건폐율·용적률·높이·주차 가정)을 새 대지 것으로 바꾸면 같은 순서로 진행할 수 있습니다. 새 대지 자료는 원본 작업 폴더의 대지 조사 템플릿으로 만듭니다 (이 저장소에는 포함되지 않음).
